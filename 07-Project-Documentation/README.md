# Project Documentation

## Project Title
Script Controlled ACL Restrict Record Access Based on Field Value

## Project Overview
This project implements access control using a Script-Controlled ACL. The system restricts or allows record access based on a specific field value.

## Purpose
The purpose of this project is to provide secure and controlled access to records.

## Technologies Used
- ServiceNow
- ACL
- Scripting

## Project Workflow
1. Identify the required record and field.
2. Configure the ACL.
3. Add the access control script.
4. Test the ACL with different users.
5. Verify the access results.
6. Document the final implementation.

## Benefits
- Improves record security.
- Prevents unauthorized access.
- Provides dynamic access control.
- Makes access management easier.

## Final Result
The project successfully demonstrates record access restriction based on the configured field value.

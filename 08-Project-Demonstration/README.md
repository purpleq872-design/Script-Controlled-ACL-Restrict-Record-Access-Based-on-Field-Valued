# Project Demonstration

## Project Title
Script Controlled ACL Restrict Record Access Based on Field Value

## Project Demonstration
The project demonstrates how a Script-Controlled ACL can restrict or allow record access based on a specific field value.

- Project Name
- Project Purpose
- Project Benefits
- Project Execution

## Project Execution
1. Open the ServiceNow application.
2. Open the configured record.
3. Show the ACL configuration.
4. Show the access control script.
5. Test the record with an authorized user.
6. Test the record with an unauthorized user.
7. Show the final access result.

## Final Output
The system successfully controls record access based on the configured field value.
